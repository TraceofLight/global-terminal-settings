# Archived Plans

Historical record of design docs and implementation plans that have already been executed. Each file keeps its original body untouched; a short `> Status:` header at the top marks divergences from the shipped code and points to the current source of truth.

These files are not maintained. For current behavior, prefer the files listed under each entry's **Current source of truth** line, or the top-level setup guides and `docs/ux-contract.md`.

- [`wezterm-nushell-bootstrap.md`](wezterm-nushell-bootstrap.md) — implementation plan for the Windows + macOS bootstrap.
